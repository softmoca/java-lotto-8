# java-lotto-precourse

# 요구사항 이해 및 분석 정리

### 명사 개념 찾기

- 로또 번호 (1~45)
- 로또 (6개)
- 당첨 번호 (6개)
- 보너스 번호 (1개)
- 등수 (1~5등)
- 구입 금액
- 수익률
- 당첨 내역`

### 동사 행동 찾기 (수동태 → 능동태 변환)

- 발행한다 (로또를)`→ 발행한다 (시스템이 로또를)
- 뽑는다 (번호를)`→ 뽑는다 (시스템이 번호를)
- 입력받는다 (금액을, 당첨 번호를)
- 비교한다 (번호를)`→ 비교한다 (로또가 당첨 번호와)
- 계산한다 (수익률을)
- 출력한다 (결과를)`

### 복잡한 행위 분해

"당첨을 확인한다"

1. 로또 번호와 당첨 번호를 비교한다
2. 일치하는 개수를 센다
3. 보너스 번호 포함 여부를 확인한다
4. 등수를 판단한다
5. 상금을 계산한다

## 업무 규칙

1. 로또 번호는 1부터 45까지의 숫자다.
2. 로또 한 장은 중복되지 않는 6개의 번호를 갖는다.
3. 당첨 번호는 중복되지 않는 6개의 번호를 갖는다.
4. 보너스 번호는 당첨 번호와 중복되지 않는 1개의 번호다.
5. 로또 한 장의 가격은 1,000원이다.
6. 구입 금액은 1,000원 단위로 입력받는다.
7. 등수는 일치하는 번호 개수에 따라 결정된다:
    - 6개 일치: 1등 (2,000,000,000원)
    - 5개 + 보너스: 2등 (30,000,000원)
    - 5개 일치: 3등 (1,500,000원)
    - 4개 일치: 4등 (50,000원)
    - 3개 일치: 5등 (5,000원)
    - 그 외: 낙첨
8. 수익률은 (총 상금 / 구입 금액 * 100)로 계산한다.
9. 수익률은 소수점 둘째 자리에서 반올림한다.

## 기능 요구사항

1. 시스템은 구입 금액을 입력받을 수 있다.
2. 시스템은 구입 금액만큼 로또를 발행할 수 있다.
3. 시스템은 발행된 로또를 출력할 수 있다.
4. 시스템은 당첨 번호를 입력받을 수 있다.
5. 시스템은 보너스 번호를 입력받을 수 있다.
6. 시스템은 로또와 당첨 번호를 비교할 수 있다.
7. 시스템은 당첨 통계를 계산할 수 있다.
8. 시스템은 수익률을 계산할 수 있다.
9. 시스템은 결과를 출력할 수 있다.

- 계산한다 (로또가 일치 개수를)

## 시나리오 메시지 중심으로 재검토

### 시나리오 1: 로또 구입

사용자: "8000원 이요 !"   
→ 시스템: "몇 장?" 계산 필요     
→ LottoMachine: "8장 발행해"    
→ 각 Lotto: "6개 번호 뽑아"   
→ LottoNumber: "유효한 번호야?"

메시지:

- calculateCount(money) → 장수 계산
- issue(count) → 발행
- pickNumbers() → 번호 뽑기
- validate(number) → 검증

### 시나리오 2: 당첨 확인

사용자: "당첨 번호는 1,2,3,4,5,6"   
사용자: "보너스는 7"   
→ WinningLotto: "저장해"       
→ 각 Lotto: "당첨 번호와 비교해"     
→ Lotto: "몇 개 일치?" → matchCount()       
→ Lotto: "보너스 있어?" → hasBonus()     
→ WinningLotto: "등수 판단해" → determineRank()

메시지:

- match(winningLotto) → 비교
- countMatches(numbers) → 일치 개수
- hasBonus(bonus) → 보너스 여부
- determineRank(matchCount, hasBonus) → 등수 판단
