# 요구사항 이해 및 분석 정리

### 명사 개념 찾기

- 로또 번호 (1~45)
- 로또 (6개)
- 당첨 번호 (6개)
- 보너스 번호 (1개)
- 등수 (1~5등)
- 구입 금액
- 수익률
- 당첨 내역`

### 동사 행동 찾기 (수동태 → 능동태 변환)

- 발행한다 (로또를)`→ 발행한다 (시스템이 로또를)
- 뽑는다 (번호를)`→ 뽑는다 (시스템이 번호를)
- 입력받는다 (금액을, 당첨 번호를)
- 비교한다 (번호를)`→ 비교한다 (로또가 당첨 번호와)
- 계산한다 (수익률을)
- 출력한다 (결과를)`

### 복잡한 행위 분해

"당첨을 확인한다"

1. 로또 번호와 당첨 번호를 비교한다
2. 일치하는 개수를 센다
3. 보너스 번호 포함 여부를 확인한다
4. 등수를 판단한다
5. 상금을 계산한다
